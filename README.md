# BerryPop AI Advertisement Project

## 1. 프로젝트 소개

이 프로젝트는 생성형 AI 도구를 활용하여 가상의 브랜드 광고 영상을 제작하는 과제입니다.  
브랜드 기획, 이미지 생성, 영상 변환, 배경음악 제작, 최종 편집까지 AI 도구를 사용하여 10초 이내의 광고 영상을 완성하는 것이 목표입니다.

## 2. 브랜드 정보

- 브랜드명: BerryPop
- 제품: 딸기 탄산음료
- 타겟: 상큼하고 가벼운 음료를 좋아하는 10~20대
- 브랜드 분위기: 상큼함, 청량함, 밝음, 에너지
- 핵심 메시지: 톡 터지는 상큼함, BerryPop!

## 3. 광고 콘셉트

나른하고 지친 오후에 BerryPop 딸기 탄산음료를 마시며 상큼한 에너지를 얻는다는 내용의 광고입니다.  
딸기, 탄산, 얼음, 밝은 핑크색 분위기를 활용하여 제품의 청량하고 상큼한 이미지를 표현했습니다.

## 4. 영상 구성

광고 영상은 총 4개의 장면으로 구성됩니다.

| Scene | 장면 내용 | 길이 | 화면 카피 |
|------|----------|------|-----------|
| Scene 1 | 지친 오후 | 2초 | 나른한 오후, |
| Scene 2 | BerryPop 음료 등장 | 2초 | 상큼함이 필요할 때 |
| Scene 3 | 딸기와 탄산 효과 | 2초 | 톡 터지는 딸기 에너지 |
| Scene 4 | 브랜드 엔딩 | 3초 | BerryPop / 톡 터지는 상큼함! |

총 영상 길이: 약 9초

## 5. 사용한 AI 도구

- 이미지 생성: DALL·E 또는 Leonardo AI
- 이미지 기반 영상 변환: Pika 또는 Runway
- 배경음악 생성: Suno 또는 Udio
- 영상 편집: CapCut
- 파일 정리 및 제출: GitHub

## 6. 제작 과정

1. BerryPop 브랜드 콘셉트 기획
2. 광고 장면 4개 구성
3. 이미지 생성 AI로 각 장면 이미지 제작
4. 영상 생성 AI로 이미지를 짧은 영상으로 변환
5. AI 음악 도구로 배경음악 제작
6. CapCut에서 영상, 자막, 음악 편집
7. 최종 광고 영상 MP4로 내보내기
8. 스토리보드 PDF와 최종 영상 파일을 GitHub에 업로드

# berrypop-ai-ad
# BerryPop AI Advertisement Project

## 프로젝트 소개
생성형 AI 도구를 활용하여 10초 이내의 브랜드 광고 영상을 제작하는 프로젝트입니다.

## 브랜드 정보
- 브랜드명: BerryPop
- 제품: 딸기 탄산음료
- 타겟: 상큼하고 가벼운 음료를 좋아하는 10~20대
- 톤앤매너: 상큼함, 청량함, 밝음, 에너지
- 핵심 메시지: 톡 터지는 상큼함, BerryPop!

## 영상 구성
1. Scene 1: 지친 오후
2. Scene 2: BerryPop 음료 등장
3. Scene 3: 딸기와 탄산이 터지는 장면
4. Scene 4: 브랜드 엔딩

## 사용 도구
- 이미지 생성: DALL·E 또는 Leonardo AI
- 비디오 변환: Pika 또는 Runway
- 오디오 생성: Suno 또는 Udio
- 편집: CapCut
